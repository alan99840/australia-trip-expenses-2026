## GitHub Pages 发布

1. 在个人 GitHub 账户新建专用于此看板的仓库。
2. 将 index.html 和 .nojekyll 上传到 main 分支根目录。
3. Settings → Pages → Source 选择 Deploy from a branch。
4. Branch 选择 main，文件夹选择 / (root)，点击 Save。
5. 等待部署成功后使用 GitHub 实际显示的 Visit site 地址。

记录更新由重新发布 index.html 完成；此版本不提供在线修改数据库。
